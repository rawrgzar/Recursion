# Discovery

Before starting, read this guide, the relevant problem definition, its handoff notes, and any named parent context. Check `problems/index.yaml` for dependencies and status.

If a request is unclear, inspect the files and record the smallest concrete interpretation in the problem handoff before expanding scope. Do not rely on chat history as the only record of a decision.

For a new problem, add a folder under `problems/`, give it a stable ID, describe one checkable outcome in `problem.yaml`, and add `HANDOFF.md` with context and the next action.
