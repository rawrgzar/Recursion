# Claims and ownership

Each active task should have one clear owner. Record owner, status, and intended files in its `HANDOFF.md`.

This repository is local-first. A claim can be recorded in files without publishing a branch or contacting a remote. If contributors choose to use Git branches, use a distinct branch per task and include its ID. Do not overwrite another contributor's work; coordinate through task files and reviewable changes.

Suggested statuses are `ready`, `in_progress`, `blocked`, and `done`. Update the problem index and handoff when status changes.
