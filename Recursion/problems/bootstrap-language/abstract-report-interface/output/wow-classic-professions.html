CHRONOLOGY
  1. Train
    Rank gates

    Train Journeyman, Expert, and Artisan before the next bracket caps; character level requirements apply to higher ranks.

  2. Craft
    Save materials

    Keep every intermediate explicitly marked as saved; later rows assume you have those outputs.

  3. Gather
    Skill-based routes

    Herbalism, Mining, Skinning, and Fishing use skill targets and locations rather than fixed make counts.
