# Build outputs

Keep generated static pages and bootstrap build outputs here. `operator-brief.html`, `theme-navbar.html`, and `pancake-guide.html` are generated from YAML files by `tools/build_page.py`; `breakfast-blaster.html` is generated from `source/breakfast-blaster.rec` by `tools/compile_site.py`. Both generators use shared configurable design tokens from `tools/design.py`. The pancake guide uses local photos in `assets/` and image credits in `assets/credits.md`. `operator-brief.fragment.html` preserves the original body-fragment example. Record reproduction steps in the problem's `HANDOFF.md`.
