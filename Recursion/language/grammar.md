# Initial grammar sketch

The first example uses one statement:

```text
print "Hello World"
```

- A program is one or more statements, one per line.
- The only initial statement is `print` followed by a quoted string.
- Strings use double quotes. Escape sequences are not defined yet.
- A successful run writes each string followed by a newline.

This is a teaching prototype, not a settled specification. Record grammar changes and matching example or verification updates in the bootstrap-language problem.
